# archive/

Код, который больше не используется, но удалять его рано: вдруг понадобится
посмотреть, как было. Отсюда ничего не импортируется и не запускается.
Структура папок повторяет исходное расположение. Чтобы вернуть файл в
работу, достаточно перенести его обратно (`git mv archive/<путь> <путь>`).

| Файл | Почему в архиве |
|---|---|
| `models/cnn/extract_digit_crops.py` | Раскладывал кропы в `train/`/`val/`, а `dataset_cnn.py` ждёт плоскую структуру `<класс>/*.jpg` (её делает `build_dataset_cnn.py`). Владелец не пользуется (2026-09-29). |
| `utils/*` (11 файлов) | Утилиты подготовки датасетов и разметки, накопившиеся за время разработки. Владелец не пользуется (2026-10-01). Многие с зашитыми путями старого расположения проекта (`C:\AD\gas-meter-reader\…`, `D:\…`); `del_lb.py`, `rename.py`, `prepare_labeling_dataset.py` удаляют или переименовывают файлы — **перед запуском читать код**. Подробности по каждому — `docs/audit/utils.md`. |
| `meter_ocr/utils/compare_yolo_vs_cnn.py`, `crop_save.py`, `crops_parameters.py` | Просмотр и сравнение моделей. Заменены `python gmr.py inspect` (`tools/inspect_model.py`), который берёт те же веса и пороги, что прод. `compare_yolo_vs_cnn.py` вдобавок смотрел не на те веса. |
| `models/yolo_all_detect/labeler_yolo.py` | Разметчик рамок (Tkinter). Владелец не пользуется (2026-10-01). |
| `models/yolo_all_detect/detect_model_train.py` | **Скрипт обучения YOLO-детектора.** Владелец не пользуется (2026-10-01). Понадобится при переобучении детектора счётчика или цифр — вернуть из архива. |
| `models/yolo_all_detect/test.py` | Ручная проверка YOLO на фото. Заменён `python gmr.py inspect meter|digits`. |
